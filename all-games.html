To try a game, click the Play Game button in the corresponding box. Clicking on the README button will provide an overview, instruction, and details about the game.

These games are intended for a computer. Most of these games are unlikely to work on a mobile device. If a game has some sort of support running on mobile, it will have a Mobile section within README, with details.
